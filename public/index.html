Daten & Datenschutz

Dein GPS-Standort wird nur im Browser zur Entfernungssuche verarbeitet. Kartenkacheln werden von OpenStreetMap geladen; dabei werden IP-Adresse und Kartenausschnitt übermittelt. Adresssuchen werden über unseren Server an Nominatim (OpenStreetMap) geschickt. Navigation öffnet den gewählten externen Kartendienst mit dem Zielpunkt.

Meldungen werden samt Standort, Beschreibung und optionaler E-Mail per E-Mail an den Betreiber geschickt. Es werden keine Analyse- oder Werbe-Cookies eingesetzt.

Die öffentliche Website wird über Cloudflare ausgeliefert. Dabei verarbeitet Cloudflare Verbindungsdaten wie IP-Adresse und aufgerufene URLs. Der E-Mail-Versand erfolgt über World4You an das iCloud-Postfach des Betreibers.
